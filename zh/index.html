FAQ

常见问题解答

开始构建前你需要了解的一切。

购买后我能获得什么？

立即获取完整的 Polyship 源代码：基于 Next.js 15、TypeScript 和 Tailwind CSS，包含国际化、支付以及你所选方案中的全部模块。克隆后即可开始开发。

BYOAPI 是什么意思？

即 Bring Your Own API key（自带 API 密钥）。AI 引擎使用你自己掌控的 OpenAI、Anthropic 或 Google Gemini 密钥运行，没有加价、没有供应商锁定，随时可以切换模型。

可以用于商业项目和客户项目吗？

可以。两个方案都支持不限数量的个人与商业项目。唯一不允许的是转售或再分发这套模板本身。

支付和税务如何处理？

结账由记录商户（Merchant of Record）Lemon Squeezy 处理，它会为你计算并代缴全球的销售税和增值税。你的客户可以使用银行卡、PayPal 等方式付款。

它和 Claude、Cursor、Copilot 配合得好吗？

这正是它的设计初衷。每个功能都位于独立模块中，AGENTS.md 记录了架构与约定，AI 助手可以安全地扩展代码。

可以添加更多语言吗？

可以。在一个配置文件中添加语言代码，再放入翻译好的 JSON 词典即可。部署前 TypeScript 会提示缺失的键。
